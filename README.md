# Code for Paper Balancing Privacy and Utility in Correlated Data: A Study of Bayesian Differential Privacy

This is the code for the paper "Balancing Privacy and Utility in Correlated Data: A Study of Bayesian Differential Privacy".

The list of required python packages can be found in `requirements.txt`. The utility experiments for Galton height data and activity data can be executed by running `utility_experiment.py`. This will directly plot the results. Other plots from the paper can be generated by executing `plots_for_paper.py`.
